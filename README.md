**LaravelTypesGen** é uma biblioteca leve para **Laravel** que automatiza a sincronização entre o seu **Back-end (PHP)** e o seu **Front-end (TypeScript)**.

Ela faz o _scan_ dos seus **FormRequests** e gera **interfaces TypeScript precisas automaticamente**.

Chega de duplicar tipos manualmente entre backend e frontend.

---

# 🚀 Funcionalidades

### 🔍 Static Analysis

Lê seus arquivos sem precisar instanciar as classes.

### 🛠 Type Mapping

Converte regras do Laravel para tipos equivalentes em TypeScript.

Exemplo:

| Laravel  | TypeScript   |
| -------- | ------------ |
| string   | string       |
| integer  | number       |
| numeric  | number       |
| boolean  | boolean      |
| nullable | type \| null |

### 📦 Zero Config

Funciona **out-of-the-box** com a estrutura padrão do Laravel.

### ⚡ Developer Experience

Evita duplicação de interfaces entre **PHP e TypeScript**.

# 📦 Instalação

Instale o pacote via **Composer**:

```bash
composer require jdiassdev/thats-my-types --dev
```

## 1️⃣ Prepare seus FormRequests

Certifique-se de que seus FormRequests definem as regras no método rules().

```bash
namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;

 class StoreUserRequest extends FormRequest
 {
     public function rules(): array
        {
            return [
                'name' => 'required|string',
                'age' => 'nullable|integer',
                'email' => 'required|email',
                'is_active' => 'boolean',
            ];
        }
 }
```

# 2️⃣ Gere os Tipos

Execute o comando Artisan:

```bash
php artisan ts:generate-requests
```

# 3️⃣ Resultado

Um arquivo será gerado automaticamente em:

resources/types/api.ts

Exemplo do resultado:

```bash
/** Auto-generated by LaravelTypesGen **/

export interface StoreUserRequest {
    name: string
    age: number | null
    email: string
    is_active: boolean
}
```
